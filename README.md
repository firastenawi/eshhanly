# اشحنلي - Eshhanly ⚡

منصة ويب تربط **أصحاب السيارات الكهربائية** مع **أصحاب نقاط الشحن** (أفراد أو محطات) داخل سوريا.
النظام وظيفته الوحيدة الربط: لا حجز، لا مدة، لا دفع إلكتروني — الاتفاق والدفع نقداً بين الطرفين.

## كيف يشتغل

| الخطوة | مين | شو بيصير |
|---|---|---|
| 1 | المستخدم | يسجّل (صاحب سيارة / صاحب نقطة: فرد أو محطة) ← الحساب يكون **بانتظار التفعيل** |
| 2 | المستخدم | يدفع الاشتراك الشهري نقداً للإدارة |
| 3 | الأدمن | يفعّل الحساب ويحدد المدة (افتراضي 30 يوم) ← **ينتهي تلقائياً** بنهاية المدة |
| 4 | صاحب النقطة | يضيف نقاطه ويحدد حالتها: فعّالة / قيد الاستخدام / غير فعّالة / صيانة |
| 5 | صاحب السيارة | يبحث (محافظة، نوع شاحن) ويرسل **طلب شحن** مع رسالة |
| 6 | صاحب النقطة | **يقبل أو يرفض** مع رسالة ← يوصل إشعار فوري |
| 7 | الطرفين | **محادثة** داخل التطبيق، وبعد القبول يظهر رقم موبايل كل طرف للآخر |

- لما ينتهي الاشتراك: المستخدم ما بيقدر يستخدم التطبيق، ونقاطه بتختفي من البحث، وبيقدر يضغط «طلب تجديد».
- قبل الانتهاء بـ 3 أيام بيظهر تنبيه للمستخدم.
- الأدمن: لوحة إحصائيات، طلبات الاشتراك، تفعيل/تمديد/إلغاء تفعيل/حظر، تعيين كلمة مرور جديدة، كل النقاط، إعدادات (سعر الاشتراك، تعليمات الدفع، رقم الإدارة).

## التقنيات

- .NET 9 — Blazor Web App (Interactive Server) + MudBlazor، واجهة عربية RTL، متجاوبة مع الموبايل
- EF Core: **PostgreSQL** بالإنتاج، **SQLite** تلقائياً للتجربة المحلية
- تحديثات فورية (إشعارات/محادثة) عبر اتصال Blazor نفسه — بدون أي خدمة خارجية

## التشغيل محلياً

```bash
dotnet run --launch-profile http
```

افتح http://localhost:5080 — حساب الأدمن للتجربة (من `appsettings.Development.json`):
موبايل `0900000000` / كلمة مرور `admin123`.
قاعدة البيانات `eshhanly.db` (SQLite) تنعمل تلقائياً.

## النشر (مجاني): Render + Neon

1. أنشئ قاعدة بيانات PostgreSQL مجانية على [neon.tech](https://neon.tech) وانسخ الـ connection string (`postgres://...`).
2. ارفع المشروع على GitHub.
3. على [render.com](https://render.com): **New → Blueprint** واختر المستودع (يقرأ `render.yaml`)، أو **New → Web Service → Docker**.
4. متغيرات البيئة:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط Neon |
| `Admin__Phone` | رقم موبايل الأدمن (09xxxxxxxx) |
| `Admin__Password` | كلمة مرور قوية للأدمن |

عند أول تشغيل: الجداول تنعمل تلقائياً (migrations) وحساب الأدمن ينعمل إذا ما في أدمن.
بيشتغل كمان على أي VPS أو Railway / Koyeb / Fly.io عبر الـ `Dockerfile` (المنفذ من `$PORT` أو 8080).

> بديل `DATABASE_URL`: `ConnectionStrings__Postgres=Host=...;Database=...;Username=...;Password=...`

## تعديل قاعدة البيانات لاحقاً

```bash
dotnet ef migrations add <Name> -o Data/Migrations
```

(الـ migrations لـ PostgreSQL؛ SQLite المحلية تنعمل مباشرة من الموديل — احذف `eshhanly.db` بعد تغيير الجداول.)

## بنية المشروع

```
Data/          الجداول (Entities) + DbContext + التهيئة وإنشاء الأدمن
Services/      منطق التطبيق: الاشتراكات، النقاط، الطلبات والمحادثة، الإشعارات، الدخول
Components/    الصفحات (Pages) والمكونات المشتركة (Shared) والقالب (Layout)
```

## ملاحظات

- الدخول برقم الموبايل السوري (يقبل 09.. أو +963..).
- التوقيت يُعرض بتوقيت سوريا (UTC+3).
- يعمل على سيرفر واحد (التحديثات الفورية داخل الذاكرة) — كافي تماماً لهالحجم.
